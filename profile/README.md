## VCR.systems

### Stormworks
~~We~~ I build vehicles in Stormworks mostly to test architecture and get a rough base on what I want things to do. Probably a horrible idea to use a game for real life applications, but with Tony Pepperoni's help we can make it work. <br>

Also it gives me unlimited budget to build a rocket that goes mach 1 into the ocean without consequences :)


### Model Rocketry
The goal for the production year is to get a TVC-stablized model rocket running an A/B class motor up and safely recovered, but it's more about developing the hardware and software that can be reprinted and reused without major modifications.
